# CUACKER (Proyecto C++)

**Descripción del Proyecto**
Proyecto centrado en el diseño e implementación de estructuras de datos s en C++. Utiliza tablas hash y árboles AVL para garantizar una gestión de memoria eficiente y búsquedas de alto rendimiento.

**Tecnologías Utilizadas**
* C++
* Estructuras de Datos (Árboles AVL, Tablas Hash)

**Objetivo**
Optimizar el rendimiento computacional y la eficiencia en la asignación de memoria mediante estructuras de datos avanzadas.
